## Warp

[![test](https://github.com/ezhuk/warp/actions/workflows/test.yml/badge.svg)](https://github.com/ezhuk/warp/actions/workflows/test.yml)

A lightweight, high-performance MQTT server.

> [!NOTE]
> Warp is under active development and is not yet ready for production use.

## Getting Started

Build and run as follows:

```bash
bazel run -c opt //:warp_bin
```
